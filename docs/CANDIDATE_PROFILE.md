# Candidate profile template

This file contains no candidate data. Read it before searching or assessing fit. Fill a private copy only with facts confirmed by the candidate and references they have approved for this workflow. Keep that copy and its evidence outside version control. An empty field means unknown, not false, zero, eligible, or available.

Set `profile_path` in the task to the reviewed private copy. Without one, use this blank template for general discovery and leave candidate-specific conclusions conditional. A local path is permission to read the authorized source, not permission to upload or publish it. Send only public role terms and public employer information to search services.

Degrees do not generically replace industry experience. Record an employer's explicit degree substitution separately for each role. Keep required, preferred, unclear, directly met, transferable, and missing evidence distinct. A related department name is not proof of domain or clinical experience.

Do not store document numbers, credentials, addresses, contacts, or identity documents in this profile. Application answers must follow the exact question and confirmed current facts. Planned authorization, expected graduation, and a desired start date do not establish present work authorization. Do not create a personalized external statement from blank fields.
