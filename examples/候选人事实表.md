# Candidate fact sheet setup template

This template is blank evidence, not a candidate assessment. Keep a reviewed private
copy in the chosen local batch directory. Do not commit it or upload it to a
search service. NONE means no demonstrated evidence in this configured profile;
it does not assert that the person lacks the skill.

## 一 · Reviewed evidence

Record only confirmed facts with local evidence references. An optional publication
row has the form `| E-PUB-EXAMPLE-1ST | tag 归属：neuroimaging | confirmed evidence reference |`.
That row is an example of parser syntax, not publication evidence. Do not copy it
into a profile unless the claim is supported.

### Reviewed research duration

Leave duration unknown until the candidate's actual history has been verified.
Record the reviewed, non-overlapping research periods, as-of date and local source
IDs here. Count only the type of research the specific employer clause accepts;
do not add concurrent appointments together. A degree alone supplies no duration.

When the JD explicitly accepts research experience and requires more than zero
years, the external reviewer must copy the supported total and source IDs into
that judgment's `hard_gates.years`:

```json
{
  "verified_research_years": null,
  "research_evidence_ids": []
}
```

These are blank inputs, not a candidate history. A verified duration must be a
finite, nonnegative number and source IDs must be a nonempty list of strings
referring to reviewed local evidence. Missing or invalid evidence leaves the
experience gate conditional; a verified duration below the required years fails
the gate. No private start date or default tenure is bundled. The tool does not
automatically parse duration from this prose or certify the referenced evidence.

## 五 · Role policy and limitations

The shipped funnel and judgment rules are an early-career US healthcare/ML preset.
Confirm that this preset fits the candidate before using it. The fact-sheet table
configures domain evidence only; it does not override experience gates, work
authorization or required clinical experience. Record reviewed timing, role,
industry-experience and domain boundaries here for the external reviewer.

For optional snapshot drift detection, put a reviewed `career-archive.md` in this
same private batch directory and add `career-archive.md md5=<32 lowercase hex>`
with its actual MD5. No external vault or archive is searched.
